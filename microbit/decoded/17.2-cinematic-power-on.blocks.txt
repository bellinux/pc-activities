ACTIVIDAD: 17.2-cinematic-power-on
FUENTE: micro:bit / MakeCode 9.0.8 — "luz-encendida-ruido-animacion"  (etiquetas oficiales es-ES)

al detectar el sonido alto:
  fijar estado a no(estado)
  si estado entonces:
    para filas de 0 a 4:   // Este bloque crea una variable llamada "filas". Luego asigna valores desde 0 hasta 4 en aumentos de 1 y cada vez que toma un nuevo valor se ejecutará lo de dentro.  Es decir inicia con filas = 0, luego ejecuta lo de dentro y al terminar ahora filas = 1 y se vuelve a ejecutar todo. Una vez filas = 4 se ejecuta lo de dentro y pasa al siguiente bloque de instrucciones que no esté dentro.
      para columnas de 0 a 4:   // Este bloque crea una variable llamada "columnas". Luego asigna valores desde 0 hasta 4 en aumentos de 1 y cada vez que toma un nuevo valor se ejecutará lo de dentro.  Es decir inicia con columnas = 0, luego ejecuta lo de dentro y al terminar ahora columnas = 1 y se vuelve a ejecutar todo. Una vez columnas = 4 se ejecuta lo de dentro y pasa al siguiente bloque de instrucciones que no esté dentro.  Se puede analizar que por cada vez que el valor de fila cambia se ejecuta 5 veces el bloque donde cambia columna (0, 1, 2, 3, 4) y como filas cambia 5 veces, el bloque de "graficar x..." se ejecuta 5x5 = 25 veces, que corresponde a la cantidad total de leds.
        graficar x columnas y filas
        pausa (ms) 20
  si no:
    para filas de 0 a 4:   // Realiza lo mismo que el anterior contar con filas, solo que esta vez para apagar la luz de cada fila.
      para columnas de 0 a 4:   // Realiza lo mismo que el contar con columnas anterior, solo que se utiliza para apagar las luces en la columna actual.
        ocultar x columnas y filas
        pausa (ms) 20

al iniciar:
  fijar estado a falso
